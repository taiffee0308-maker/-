# 【有料パート本体】デジタル終活キット 一式

> note の有料ライン以降に貼る中身。または PDF/Googleドキュメントにして購入者にDL配布する。
> 目次は記事の「有料パート もくじ」と一致(第1部〜特典)。

---

## 第1部 まず5分。埋めるだけのデジタル・エンディングノート

→ 別ファイル `ending-note-template.md` の全項目をここに貼る(スマホ/メール/口座/暗号資産/サブスク/SNS/写真、記入例つき)。

**続けられる書き方のコツ**
- **金額は書かない**(変わるし、漏れたとき怖い)。書くのは「どこに・何があるか」だけ
- パスワードそのものより、**「在りか(パスワード管理アプリ名・紙の場所)」**を書くほうが安全
- 完璧を目指さない。**まずSTEP1(スマホ)だけでも書けば価値がある**

## 第2部 これを渡せば家族は迷わない ― 引き継ぎ手順書

> このページごと家族に渡せば、いざという時に「何から手をつけるか」で迷いません。

### 手順の全体像(この順番でやる)
```
STEP1 スマホ/PCを開く → STEP2 メールを確保 → STEP3 お金を止める/守る
  → STEP4 サブスクを解約 → STEP5 SNS・データを整理
```

- **STEP1 スマホ/PCを開く**:ノート「1.」のロック解除を見る。開けたら**機内モードは切らない**(遠隔ロック防止)でメールと写真を確認
- **STEP2 メールを確保**:メールは各サービスの「パスワード再発行の入口」。最優先で押さえる
- **STEP3 お金**:ネット銀行/証券は各社の「相続(死亡)窓口」へ。**通帳が無くてもノートの口座リストで存在を伝える**
- **STEP4 サブスク解約**:ノート「5.」を上から解約。ログイン不可のものは各社問い合わせ＋カード会社にも連絡
- **STEP5 SNS・データ**:LINEは削除のみ/Instagram・Facebookは追悼化or削除/写真はバックアップ後に整理

### 困ったとき早見表
| やりたいこと | 連絡先 |
|---|---|
| Googleのデータ取得/削除 | Google「故人のアカウントに関するリクエスト」フォーム |
| Apple/iCloudのデータ取得 | Appleサポート(アクセスキー＋死亡証明書が必要) |
| LINEの削除 | LINEお問い合わせフォーム |
| 各ネット銀行/証券 | 各社「相続手続き窓口」 |

### 📋 必要書類チェックリスト(家族が集めるもの)
> 手続きは「まず共通書類をそろえる → 用途ごとに追加」で進めると効率的。**戸籍謄本は複数枚必要になりがち**なので、多めに取っておくと再取得の手間が省けます。

**■ まず用意する共通書類**
- [ ] 死亡診断書(死体検案書)のコピー ※原本は死亡届に使うのでコピーを複数
- [ ] 被相続人の死亡が記載された戸籍(除籍)謄本
- [ ] 申請者(相続人)の本人確認書類(運転免許証・マイナンバーカード等)
- [ ] 申請者の認印／実印＋印鑑証明書

**■ ネット銀行・証券の相続手続きで追加**
- [ ] 被相続人の**出生から死亡までの連続した戸籍謄本**(遺言があれば死亡記載のみで足りる場合あり)
- [ ] 相続人全員の戸籍謄本
- [ ] 相続人全員の印鑑証明書
- [ ] 遺言書 または 遺産分割協議書(ある場合)
- [ ] 各社所定の「相続手続依頼書」(窓口/Webで入手)
- [ ] 通帳・カード等(あれば。なくてもノートの口座リストで可)

**■ SNS・クラウドのデータ取得／削除で追加**
- [ ] 死亡証明書(死亡が確認できる書類)のコピー
- [ ] 申請者の本人確認書類
- [ ] 申請者が**近親者であることが分かる書類**(続柄の分かる戸籍など)
- [ ] (Appleのみ)アクセスキー

> ⚠️ 必要書類は各銀行・各サービスで異なります。**手続き前に必ず各社の最新案内を確認**してください。

## 第3部 5分でできる「無料の自動引き継ぎ」設定(スマホ画面つき)

> 記事STEP5の完全版。生前に5〜10分。**やってる人は2割未満**なので、これだけで一歩先。

### A. Google「アカウント無効化管理ツール」(現在のメニュー名:アカウントが使用されなくなった場合のプラン)
一定期間ログインが無いと、指定の人(最大10人)に指定データを渡す or 自動削除する。
1. ブラウザで **`myaccount.google.com/inactive`** を開く(Googleにログイン)
   - ※ または Googleアカウント →「データとプライバシー」→ 下部「アカウントが使用されなくなった場合のプラン」からも入れる
2. 「開始」をタップ
3. **待機期間**を選ぶ … 3 / 6 / 12 / 18 か月(無操作がこの期間続くと発動)
4. 発動前に**自分へ通知が来る電話番号/メール**を設定
5. **信頼できる連絡先(データを渡す相手)**を追加(最大10人。相手ごとに渡すデータの種類を選べる)
6. 期間後に**アカウントを自動削除するか**を選ぶ
7. 内容を確認して**有効化**で完了
> 💡 Googleは最終ログインから約2年放置でも削除対象になりうる。意図して設定を。

### B. Apple「故人アカウント管理連絡先(デジタル遺産)」
死後、指定の人が「アクセスキー＋死亡証明書」でiCloudの写真・データを取得できる。
1. **設定アプリ** → 一番上の**自分の名前**
2. **「サインインとセキュリティ」**(iOS16以前は「パスワードとセキュリティ」)
3. **「故人アカウント管理連絡先」** → 「連絡先を追加」
4. 託す人を選ぶ(Apple ID不要・複数人OK)
5. 発行される**アクセスキー**を相手に共有 or 印刷して保管
> ⚠️ 死後アクセスには「アクセスキー」＋「死亡証明書」の両方が必要(**日本では戸籍謄本が一般的**)。13歳以下は申請不可。
> 💡 託す相手がiPhoneユーザーなら、アクセスキーは相手の端末に自動保存されるので、いざという時は死亡証明書を用意して「アクセスを要求」するだけ。

### C. Facebook / Instagram「追悼アカウント管理人」
- **Facebook**:右上のメニュー(≡)→「設定とプライバシー」→「設定」→**「個人の情報」→「追悼アカウントの設定」→「追悼アカウント管理人」**で友達を指定(管理人は**18歳以上**)。「死後にアカウントを削除する」を選ぶこともできる
- **Instagram**:生前の管理人指定は無し。死後に家族が「追悼化」または「削除」を申請(死亡が分かる書類が必要)
> 💡 Facebookアプリのメニュー名は更新で変わることがあります。見つからない時は設定内を「追悼」で検索。

## 第4部 つまずきポイント完全対策(無料テンプレに無い価値)

> ここが、タダのエンディングノートには絶対に無い部分。**"知らないと損する"3大ハマりどころ**を先回りで潰します。

### ① 暗号資産:「引き出せないのに課税される」への備え
- 問題:秘密鍵/リカバリーフレーズが無いと**事実上アクセス不能=資産消滅**。なのに国税庁は「パスワードを知らなくても相続税の課税対象」と答弁(2018年)。最悪**引き出せないのに課税**。
- 備え方:
  1. 取引所名・ウォレットの**存在**を必ずノートに残す(金額や鍵そのものは別保管)
  2. リカバリーフレーズは**紙に書いて金庫など物理保管**(写真・クラウドは流出リスク)
  3. 保有しているなら**早めに税理士へ相談**。相続時の評価方法を確認しておく

### ② LINE:遺族でも引き継げない → 履歴を残す方法
- 問題:規約上アカウントは本人に一身専属。**遺族は引き継ぎ不可、できるのは削除のみ**。
- 備え方:
  1. 残したいトークは**生前にトーク履歴をバックアップ**(iPhone=iCloud Drive / Android=Googleドライブ)
     - ※「標準バックアップ」は**同じOS間(iPhone→iPhone等)・テキスト中心**。写真や動画まで完全に残したいなら、その都度アルバム保存やスクショを
  2. どうしても残したい会話は**スクリーンショット**が確実
  3. 削除は遺族がLINEの問い合わせフォームから依頼(死亡が分かる情報が必要)

### ③ 写真・サブスク・各社手続きのコツ
- **写真**:クラウド(Googleフォト/iCloud)と端末内は別物。**両方**バックアップしてから整理
- **サブスク**:見落としは**カード明細**で発見。年1回課金のもの(ドメイン・年額アプリ等)に注意
- **各社の相続手続き**:必要書類は「死亡を証明する書類＋申請者の本人確認」が基本。時間がかかるので早めに着手

## 第5部 古くならせない ― 年1回3分の更新術

「一度書いて終わり」だと口座やサブスクが変わって役立たなくなる。**年1回の見直し**を仕組み化。

- やり方(どれか1つ):①スマホカレンダーに毎年の繰り返し予定(例:1月1日や誕生日)/②リマインダーアプリの年次繰り返し/③紙派は表紙に「次回見直し:__年__月」
- 見直しチェック(3分):
  - [ ] 新しく契約したサブスク/口座/SNSを追加した
  - [ ] 解約・退会したものを消した
  - [ ] パスワードを変えたものを更新した
  - [ ] 保管場所を家族がまだ把握しているか確認した
