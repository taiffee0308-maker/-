## 第6部 サービス別「死後の手続き」早見表

> いざという時、家族が「このサービスはどうするの?」で迷わないための一覧。
> ⚠️ 規約・窓口は変わることがあります。手続き前に各社の最新案内を確認してください。

### 💰 お金(残高は相続対象になりうる → 早めに連絡)
| サービス | 残高・資産の扱い | 死後の手続き | 必要書類の目安 |
|---|---|---|---|
| ネット銀行(楽天銀行など) | 預金は相続対象 | カスタマーセンターへ電話 → 所定の相続払戻手続依頼書を提出。オンライン/郵送中心 | 相続手続依頼書、被相続人の戸籍、相続人の戸籍・印鑑証明 等 |
| ネット証券(楽天証券・SBI証券など) | 有価証券は相続対象 | 相続窓口へ連絡 → 相続手続依頼書(相続人全員の署名捺印)。Web申込＋郵送 | 上記＋証券会社所定書類 |
| PayPay(電子マネー) | **PayPayマネー/マネーライトは相続可**(2021年規約改定)。**ポイントは相続不可** | カスタマーサポートへ死亡連絡 → 書類提出 → 手数料を引いて法定相続人の口座へ払戻 | 死亡が分かる書類、相続関係・本人確認書類 |

### 📺 サブスク(止めないと課金され続ける → 最優先で解約)
| サービス | ログインできる場合 | ログインできない場合 |
|---|---|---|
| Amazon(プライム等) | アカウント・リスト →「プライム会員情報の管理」→「会員をキャンセル」 | カスタマーサービスへ死亡連絡。死亡証明書・続柄書類を求められることあり |
| Netflix | ログイン →「メンバーシップのキャンセル」 | カスタマーサポートへ連絡し解約依頼 |
| その他(Spotify/アプリ課金 等) | 各アプリ/サイトの「解約・退会」 | 各社サポートへ連絡。難しければ**カード会社に連絡**して定期課金を止める |

### 💬 SNS・データ
| サービス | 引き継ぎ可否 | 死後の手続き |
|---|---|---|
| LINE | ❌引き継ぎ不可(削除のみ) | 問い合わせフォームから削除依頼 |
| X(旧Twitter) | ❌追悼なし・削除のみ | プライバシーフォーム →「亡くなられたユーザーのアカウント削除リクエスト」→ 後日 身分証・死亡証明書を提出(近親者限定) |
| Instagram | 追悼化 or 削除 | 近親者が申請(死亡が分かる書類が必要) |
| Facebook | 追悼化 or 削除(生前に管理人指定可) | 管理人が管理、または近親者が申請 |
| Google | データ取得 or 削除 | 「故人のアカウントに関するリクエスト」フォーム(生前の無効化管理ツール設定が理想) |
| Apple/iCloud | データ取得 | 故人アカウント管理連絡先＋アクセスキー＋死亡証明書(戸籍謄本) |

## 第7部 もしもの時の「時系列やることリスト」

> 残された家族が、いつ・何をすればいいかを時間軸で整理。慌てず順番に。

**■ 〜数日(直後)**
- [ ] スマホ/PCのロックを解除(ノート「1.」)
- [ ] メールにアクセスできるようにする(ノート「2.」)
- [ ] 葬儀に使う写真をスマホ/クラウドから取り出す

**■ 〜2週間**
- [ ] サブスクを解約(放置=課金が続く。ノート「5.」)
- [ ] 必要な戸籍謄本・印鑑証明などをまとめて取得(複数枚)

**■ 〜1か月**
- [ ] ネット銀行・証券の相続窓口へ連絡(ノート「3.」)
- [ ] 暗号資産があれば税理士に相談(ノート「4.」)
- [ ] 電子マネー(PayPay等)の残高の払戻手続き

**■ それ以降(落ち着いてから)**
- [ ] SNS・メールアカウントを希望どおり削除/追悼化(ノート「2.」「6.」)
- [ ] 写真・データのバックアップと整理(ノート「7.」)

## 🎁 追加特典① 家族に渡す「もしもの1枚カード」

> 財布や手帳に入れておくカード。普段は中身を見せず、"在りか"だけ家族と共有しておくのがコツ。
> 下をコピーして印刷 → 名刺サイズに切るだけ。

```
┌─────────────────────────────┐
│  【私にもしものことがあったら】           │
│                                         │
│  デジタル終活ノートを残しています。       │
│                                         │
│  ・ノートの保管場所： ________________   │
│  ・最初に開く人　　： ________________   │
│  ・まず連絡してほしい人と連絡先：         │
│    ____________________________________ │
│                                         │
│  ※スマホのロック解除方法はノートに記載    │
└─────────────────────────────┘
```

## 🎁 追加特典② 対象別テンプレ(追記する項目)

エンディングノートに、状況に応じて足すと安心な項目。

### 一人暮らしの人へ(発見が遅れがち=備えが超重要)
- [ ] 緊急連絡先(離れて暮らす家族・親族)を複数
- [ ] 賃貸契約・大家/管理会社の連絡先
- [ ] ペットがいる場合の預け先(下記)
- [ ] 公共料金・スマホの契約情報

### ペットを飼っている人へ
- [ ] ペットの種類・名前・かかりつけ動物病院
- [ ] もしもの時に世話を頼みたい人
- [ ] 食事・薬・性格などの引き継ぎメモ

### 親に書いてもらう(子世代が渡す)
- まず「0.家族へ」「1.スマホ」「3.お金」の3つだけ埋めてもらう(全部は負担)
- 「相続のため」より「**スマホの引き継ぎのため**」と言うと進めやすい
