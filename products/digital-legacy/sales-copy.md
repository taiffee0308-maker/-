# 販売ページ設計(note 用)

note は「タイトル」「最初の数行」「ハッシュタグ」で検索・回遊からの流入が決まる。
ここを設計するのが "メルカリ的に置くだけで売れる" の肝。

---

## 1. タイトル案(検索される言葉を前に置く)

note内・Google検索の両方で拾われる語 =「デジタル遺品」「終活」「エンディングノート」。
迷ったら **A** 推奨(検索語＋ベネフィット＋"今日できる"の3点入り)。

- **A(推奨)**:【保存版】デジタル遺品の片付け方｜残された家族を困らせない、今日やる5つのこと(エンディングノート テンプレ付)
- B:スマホのロック、家族は解除できますか？ デジタル終活・完全ガイド【テンプレ付】
- C:親にもしものことがある前に。デジタル遺品・エンディングノートの作り方
- D:一人暮らしの「もしも」に。0円から始めるデジタル終活キット

## 2. 価格設定

- **初回ローンチ**: 300円(まず"売れる感覚"と最初のレビューを取る価格)
- 軌道に乗ったら **500〜980円** へ。レビュー・購入数が増えてから上げる
- note の有料記事 or 有料マガジンで設定。返金や価格変更は後からでも可

> 戦略:最初は安く出して **購入数・スキ・レビューの実績** を作る → その実績が次の客を呼ぶ(プラットフォーム内SEOで上位化)。メルカリで最初に安く売って評価を貯めるのと同じ。

## 3. ハッシュタグ(note 内回遊用 / 5〜8個)

```
#終活  #デジタル遺品  #エンディングノート  #終活準備
#おひとりさま  #相続  #ライフハック  #保存版
```

## 4. 説明文(記事冒頭の無料で見える部分=ここで買うか決まる)

> ※ note記事本文の無料パートがそのまま「説明文」になる設計。
> 最初の3行で「自分ごと」と思わせるのが勝負。本文の「スマホのロック、解除できますか？」から始める導入をそのまま使う。

## 5. サムネイル画像(0円で作る)

- Canva 無料テンプレで作成(「終活」「シンプル」で検索)
- 推奨トーン:**白基調・落ち着いた青/緑・読みやすい大きめ文字**。重すぎず、安心感を出す
- 入れる文字:「デジタル遺品の片付け方」「今日やる5つのこと」程度に絞る

# 横展開ロードマップ(売れたら次へ)

同じ中身を使い回して、別の"置き場"でも売る。1回作れば多面展開できるのが強み。

1. **note(今ここ)** … 最速で需要検証・最初の売上
2. **Kindle(KDP)** … 同じ内容を電子書籍化。「終活」本は検索需要が太く、印税ストックになる
3. **ココナラ** … 「あなた専用のデジタル終活シート作成・相談」を単価UPで提供(代行は粗利が高い)
4. **BOOTH / Gumroad** … テンプレ単体をデジタルDL商品として売り切り
5. **将来:アプリ/SaaS** … "dead man's switch(生存確認が途切れたら指定の人へ通知)" として製品化。ストック収益＆スケール

> 検証の合言葉:**「note で1件でも売れたら、需要がある証拠。そこから階段を上る」**
