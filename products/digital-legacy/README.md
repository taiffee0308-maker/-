# デジタル遺品キット ― 終活デジタル商品(第1弾)

「全人類が市場(=死・終活)」× 「0円スタート」× 「プル型の置き場で売る」で立ち上げる
最初のデジタル商品。

## 中身

| ファイル | 役割 |
|---|---|
| `note-article.md` | 売り物の本体。無料パート(集客)＋有料パート(キット)の構成 |
| `ending-note-template.md` | 購入者がもらう「商品価値」=記入式エンディングノート |
| `sales-copy.md` | タイトル案・価格・ハッシュタグ・サムネ・横展開ロードマップ |

## 出すまでの手順(note 版・今日できる)

1. note に登録(無料・即時)
2. `note-article.md` の本文を新規記事に貼る
3. 「有料エリアの設定」で、有料パートの境目(`＼ ここから有料パート ／`)に有料ラインを置く
4. `ending-note-template.md` の中身を有料パート内に貼る(or ファイル配布)
5. `sales-copy.md` のタイトル・ハッシュタグ・価格(まず300円)を設定
6. Canva でサムネを作って公開 🎉
